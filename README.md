# SIPASAR-Sistem-Pengaduan-Sarana-Sekolah-
SIPASAR adalah aplikasi backend berbasis PHP Native dan MySQL untuk mengelola pengaduan sarana sekolah sesuai dokumen UKK, memungkinkan siswa mengirim aspirasi berbasis teks dan admin memprosesnya melalui login berbasis role, pengelolaan status Menunggu, Proses, dan Selesai, serta pencatatan histori dan umpan balik pengaduan secara terpusat.
